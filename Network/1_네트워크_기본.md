# 1. 네트워크 기본

## **네트워크란?**

네트워크란, **두 대 이상의 컴퓨터나 장치(Node)들이 링크(Link, 유선 또는 무선)를 통해 연결되어 서로 데이터를 주고받을 수 있는 통신 망**을 의미한다. 네트워크의 개념을 확장하여 전 세계 컴퓨터 네트워크를 연결시켜둔 게 바로 인터넷이다.

> 인터넷 = 네트워크들의 네트워크 (network of networks)

<br>

### **네트워크 구성요소**

**노드 (Node)** - 네트워크에 연결된 모든 장치 (ex| PC, 스마트폰, 라우터, 스위치 등)

**링크 (Link)** - 노드를 연결해주는 물리적/논리적 통로 (ex| 랜선같은 **유선링크**, 와이파이나 LTE같은 **무선링크**)

**프로토콜 (Protocol)** - 컴퓨터들이 대화할 때 사용하는 통신 규칙

<br>

## **네트워크의 규모 (LAN, WAN, MAN)**

네트워크를 얼마나 넓은 범위를 연결하느냐에 따라 세 가지로 나눌 수 있다.

<br>

### **✔️ LAN (Local Area Network, 근거리 통신망)**

좁은 지역을 연결하는 네트워크로 집, 사무실, 건물 하나 정도의 범위이다.

**범위가 좁기** 때문에 **통신 지연이 적어 속도가 빠르다**.

### **✔️ WAN (Wide Area Network, 광역 통신망)**

아주 넓은 지역을 연결하는 네트워크로, 도시와 도시 혹은 국가와 국가를 잇는 규모이다. 여러 LAN을 연결한 형태를 띈다. ex| 인터넷

**통신사 (ISP)** 가 제공하는 회선을 통해 멀리 떨어진 네트워크들이 연결되기 때문에, **속도가 느리고 구조가 복잡**하다.

### **✔️ MAN (Metropolitan Area Network, 도시권 통신망)**

LAN과 WAN의 중간 규모로 하나의 도시를 커버하는 크기이다.

<br>

> **🔗 VPC (Virtual Private Cloud)**
>
> 클라우드 안에 만든 나만의 가상 네트워크를 의미한다.
>
> 예전에는 회사가 서버를 구매해 사무실에 두고 LAN으로 연결했지만, 지금은 클라우드를 쓰는 회사가 많아졌다. 클라우드에 회사 전용 LAN을 만드는게 VPC이다. 즉, 물리적 LAN을 클라우드에서 가상으로 재현한 것으로 이해하면 된다.

<br>

## **프로토콜 (Protocol)**

**프로토콜**은 네트워크에서 **데이터를 주고받기 위해 정한 공통의 규칙과 약속**이다. 데이터를 어떤 형식으로 만들지, 어떤 순서대로 보낼지, 오류가 나면 어떻게 처리할지 등을 미리 정해두는 것이다.

### **프로토콜이 정하는 것들**

**형식 (Syntax)** : 데이터를 어떤 구조로 담을지에 대한 약속. 어디까지가 주소이고, 어디까지가 실제 내용인지 정한다.

**의미 (Semantics)** : 각 부분이 무슨 뜻인지, 오류가 생기면 어떻게 대응할지를 정한다.

**순서 (Timing)** : 언제, 얼마나 빠르게 데이터를 주고받을지 정한다.

<br>

앞으로 계층별로 많은 프로토콜을 정리하게 되는데 간단하게 보면 다음과 같다.

- HTTP : 웹에서 데이터를 주고받는 규칙
- TCP/UDP : 데이터를 안정적으로 혹은 빠르게 전송하는 규칙
- IP : 목적지를 찾아 데이터를 전달하는 규칙
- SMTP : 이메일을 보내는 규칙

<br>

## **계층 구조 (OSI 7계층과 TCP/IP 4계층)**

**OSI 7계층**

국제표준화기구 (ISO)가 만든 참조모델로, 네트워크 통신을 7개의 층으로 나누었다.

```
7. 응용 계층 (Application)   - 사용자와 직접 상호작용 (HTTP, SMTP)
6. 표현 계층 (Presentation)  - 데이터 형식 변환, 암호화
5. 세션 계층 (Session)       - 연결 세션 관리
4. 전송 계층 (Transport)     - 종단 간 신뢰성 (TCP, UDP)
3. 네트워크 계층 (Network)   - 경로 설정, IP 주소 (IP, 라우팅)
2. 데이터링크 계층 (Data Link) - 인접 노드 간 전송 (MAC, 이더넷)
1. 물리 계층 (Physical)      - 실제 비트를 전기신호로 (케이블, 전파)
```

**TCP/IP 4계층**

실제 인터넷에서 현실적으로 사용되는 모델로, OSI를 실용적으로 묶은 모델이다.

```
4. 응용 계층 (Application)    - OSI의 5,6,7 통합 (HTTP, DNS, SMTP)
3. 전송 계층 (Transport)     - TCP, UDP
2. 인터넷 계층 (Internet)    - IP, 라우팅
1. 네트워크 접근 계층         - OSI의 1,2 통합 (이더넷, MAC)
```

<br>

OSI는 이론적 참조모델이고, TCP/IP는 실제 구현모델이다.

```
OSI 7계층              TCP/IP 4계층
┌─────────────┐
│ 7. 응용     │  ┐
│ 6. 표현     │  ├──→  응용 계층
│ 5. 세션     │  ┘
├─────────────┤
│ 4. 전송     │  ───→  전송 계층
├─────────────┤
│ 3. 네트워크 │  ───→  인터넷 계층
├─────────────┤
│ 2. 데이터링크│  ┐
│ 1. 물리     │  ├──→  네트워크 접근 계층
└─────────────┘  ┘
```

<br>

### **계층을 나누는 이유**

**모듈화** - 독립적 교체가 가능하기 때문에, 각 계층이 자기 역할만 책임지고 다른 계층의 동작을 몰라도 됨

**유지보수와 문제해결 용이** - 문제가 생겼을 때 어느 계층의 문제인지 나눠서 볼 수 있음
