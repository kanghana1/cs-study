# 6. 데이터링크 계층 (Data Link Layer)

## **데이터링크 계층이란?**

네트워크 계층이 목적지까지의 전체 경로를 다룬다면, 링크 계층은 다음 노드까지의 전달을 담당한다. 즉, 한 홉(hop) 전송을 담당한다.

데이터를 프레임 단위로 묶고, 어느 기기로 보낼지 지정하는 역할을 하는데 이때 사용하는 주소가 MAC 주소이다.

<br>

## **MAC 주소 (Media Access Control Address)**

**MAC 주소**는 **네트워크 장비에 물리적으로 부여된 고유 식별자**이다. 제조시점에 하드웨어에 새겨지기 때문에 전세계에서 유일하다.

```
예: 00:1A:2B:3C:4D:5E

48비트를 16진수로 표현
콜론(:)으로 6부분 구분
```

### **IP주소와의 차이점**

둘 다 주소이지만 성격이 다르다.

```
IP 주소  → 논리적 주소, 네트워크 위치에 따라 바뀜 (변동)
MAC 주소 → 물리적 주소, 기기에 고정 (불변)
```

**MAC 주소**는 **한 구간 안에서 실제 기기를 찾을 때 사용하는 주소**이고, **IP**는 **전체 경로**를 위한 주소이다.

그래서 실제 데이터가 전달될 때 최종 **목적지 IP는 그대로 유지되지만, MAC 주소는 구간마다 바뀐다.**

<br>

## **이더넷 (Ethernet)**

**이더넷(Ethernet)** 은 가장 많이 쓰이는 LAN 기술이다. LAN은 Local Area Network의 약자로, **한정된 지역 안에서만 통신하는 네트워크**를 말한다. 이더넷은 데이터를 **프레임(Frame)** 이라는 단위로 묶어서 전송한다

### **이더넷 프레임 구조**

핵심만 보면 다음과 같다.

```
[목적지 MAC | 출발지 MAC | 타입 | 데이터 | FCS]
```
- **목적지 MAC / 출발지 MAC**
  - 이 프레임을 어느 기기에서 어느 기기로 보내는지
- **타입**
  - 안에 담긴 데이터가 어떤 상위 프로토콜인지 (ex| IP)
- **데이터**
  - 상위 계층(네트워크 계층)에서 내려온 실제 내용
- **FCS(Frame Check Sequence)**
  - **오류 검출용**
  - 전송 중 데이터가 손상됐는지 확인한다. 손상됐으면 그 프레임을 버린다.

<br>

## **ARP (Address Resolution Protocol)**

**ARP**는 **IP 주소를 MAC 주소로 변환**해주는 프로토콜이다.

보통 우리는 DNS 등으로 목적 IP는 알고있으나, 데이터를 전달하기 위해서는 MAC 주소가 필요하다. 이런 상황에서 **IP를 이용해 MAC 주소를 반환해주는 프로토콜**이 바로 ARP이다.

동작 방식은 아래와 같이 브로드캐스트를 이용한다.

```
1. ARP 요청 (브로드캐스트)
    네트워크의 모든 기기에게 뿌림 (브로드캐스트)
        ↓
2. 해당 IP를 가진 기기만 응답 (유니캐스트)
   → 요청한 기기에게만 직접 답함
        ↓
3. 이제 MAC을 알았으니 프레임을 만들어 전달 가능
```

<br>

### **ARP 캐시**

매번 IP를 보내고 MAC 주소는 받는 게 비효율적이기 때문에, 한 번 알아낸 **IP-MAC 매핑은 ARP 캐시에 잠시 저장**해둔다.
